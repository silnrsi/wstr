## Script description

Pallava script is an important epigraphical script descended from Brahmi that was used between the 4th and 9th centuries in South Asia. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Pallava script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
