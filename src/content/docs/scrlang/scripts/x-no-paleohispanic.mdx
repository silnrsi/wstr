## Script description

The Northern Palaeohispanic script was disunified from the Southern Palaeohispanic script. 

<details>
<summary>Read the full description...</summary>It includes the north‐eastern Iberian and the Celtiberian script. The script is on the Script Encoding Initiative's list of scripts to encode.
