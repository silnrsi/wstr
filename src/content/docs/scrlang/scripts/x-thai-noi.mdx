## Script description

Very little is known about the Thai Noi or Tai Noi script. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Thai Noi script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
