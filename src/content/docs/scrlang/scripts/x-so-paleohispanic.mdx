## Script description

The Southern Palaeohispanic script was disunified from the Northern Palaeohispanic script. 

<details>
<summary>Read the full description...</summary>It includes the south‐eastern Iberian script, the south‐western or Tartessian script, the Turdetan script and the Espanca abecedary. The script is on the Script Encoding Initiative's list of scripts to encode.
</details>
