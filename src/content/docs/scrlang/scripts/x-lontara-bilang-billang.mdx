## Script description

The Lontara’ bilang-bilang cipher script is used in Buginese poetry. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Lontara bilang-bilang script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
