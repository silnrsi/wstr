## Script description

Pabuchi is a script used for writing the Sirmauri and Mahasui languages. It has been used by the astrologers in Himachal Pradesh, India. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Pabuchi script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
