## Script description

Very little is known about the Pungchen script. It is associated with the Bön religious tradition and was used for writing texts in the Zhang Zhung language. A closely related script is the Pungchung script. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Pungchen script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
