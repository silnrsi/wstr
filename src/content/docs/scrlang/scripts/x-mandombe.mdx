## Script description

Mandombe, which means “for the Blacks”, is a modern African script which was invented in 1978 by David Wabeladio Payi. ## Unicode status

The Mandombe script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
