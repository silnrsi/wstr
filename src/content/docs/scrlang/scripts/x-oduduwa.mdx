## Script description

The Odùduwà script, invented by Olóyè Tolúlàṣẹ Ògúntósìn of Benin in 2011, is used to write the Yoruba language. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Odùduwà script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
