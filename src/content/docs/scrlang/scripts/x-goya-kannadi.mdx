## Script description

Goya Kannadi  is reported to have been used by the Konkani community from the 16th-19th century. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Goya Kannadi script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
