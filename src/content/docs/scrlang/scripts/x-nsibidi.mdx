## Script description

There is an ancient Nsibidi script and a newer Nsibidi (Neo-Nsibidi) script. Very little is known about either. The scripts are associated with the Igbo language of Nigeria. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Nsibidi script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
