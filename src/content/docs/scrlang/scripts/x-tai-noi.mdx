## Script description

Very little is known about the Tai Noi or Thai Noi script. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Tai Noi script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
