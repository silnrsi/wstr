The Cirth script is not yet in Unicode. At one point the script had a tentative allocation in the [Roadmap to the SMP](http://www.unicode.org/roadmaps/smp/) for the Unicode Standard. However, it is no longer in the roadmap.

The [ConScript Unicode Registry][conscript] has defined the U+E080..U+E0FF range of the Unicode "Private Use Area" for Cirth.

## Blocks

None.

## Proposals and documents

One proposal for its inclusion was submitted to the Unicode Technical Committee and WG2:
- 1997-09-18 Proposal to encode Cirth Plane 1 — Michael Everson (WG2 N1642.htm (not online), L2/97-272 (not online))
