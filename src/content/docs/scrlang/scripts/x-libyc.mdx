## Script description

The ancient Libyc script could possibly be unified with the Tifinagh script. It can be written in multiple directions, with multiple glyph variants depending on the direction of the text.

## Unicode status

The Libyc script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
