## Script description

The Kurukh Banna script (or Kurux Banna) is an alphasyllabary based upon the Brahmi model. The script was developed by Basudeo Ram Khalkho between 1990-1991 for the Kurukh language. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Kurukh Banna script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts to Encode”. Contributions here may support their efforts.
