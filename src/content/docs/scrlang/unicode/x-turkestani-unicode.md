The Turkestani script is not yet in Unicode. It may be disunified into Tocharian and Khotanese.

## Blocks

None.

## Proposals and documents

A number of proposals for its inclusion have been submitted to the Unicode Technical Committee:
- 2014-08-02 Preliminary Proposal to Encode the Turkestani Script — Lee Wilson ([L2/14-192](http://www.unicode.org/cgi-bin/GetMatchingDocs.pl?L2/14-192))
- 2026-10-13 Preliminary proposal for Turkestan Brahmi within the Brahmi block -- Francesco Catoni ([L2/26-252](https://www.unicode.org/cgi-bin/GetMatchingDocs.pl?L2/26-252))
  - _Recommendations to UTC #189 (October 2026) on Script Proposals ([L2/26-239](https://www.unicode.org/cgi-bin/GetMatchingDocs.pl?L2/26-239)) (See point 2.12)_
  - _UTC #189 Minutes ([L2/26-232](https://www.unicode.org/L2/L2026/26232.htm)) (See D.1 2.12 for decision and action items)_
