## Script description

The N’ti script, invented in 1966, has been used to write the Soninke language of West Africa. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The N’ti script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
