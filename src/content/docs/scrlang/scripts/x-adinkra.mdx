## Script description

Adinkra Alphabet is a phonetic writing system derived from Adinkra symbols. Adinkra Alphabet was created in 2015 with 26 characters. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Adinkra alphabet is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
