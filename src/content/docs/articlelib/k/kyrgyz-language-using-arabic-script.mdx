Fonts which are intended to support the Kyrgyz language must include some different design features than those designed for standard Arabic.

### ARABIC LETTER YEH WITH HAMZA ABOVE

The position of the :usv[0626]{usv char name} is different for the Kyrgyz language. See [Different kinds of hamza characters in Arabic script](/articlelib/d/different-kinds-of-arabic-hamza#arabic-letter-yeh-with-hamza-above).

### ARABIC LETTER KIRGHIZ OE

:usv[06c5]{usv char name} has had different shapes in the Unicode codecharts. It has now been standardized. See [Glyph Variant for U+06C5](/articlelib/g/glyph-variant-for-u-06c5) for further explanation.

### Opentype

In order to add OpenType support for the Kyrgyz language it is important to note that the ISO 639-3 is `kir`, the two letter code is `ky`, and the Opentype language tag is `KIR `. This information is valuable for testing.

We have found that the OpenType code in the font should use the [Opentype language tag][ot-lang] (`KIR `). However, when testing the font in html, it will be necessary to use `lang="ky"`.

In addition, when converting an html file to pdf using [weasyprint][weasyprint], we had to convert the code to `kir` (`-e s/lang=\"ky\"/lang=\"kir\"/`).
