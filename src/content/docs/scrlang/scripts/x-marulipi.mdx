## Script description

Marulipi is an artificially constructed alphabet invented in 2001 for the purpose of writing script less tribal languages. The script is on the Script Encoding Initiative's list of scripts to encode.

## Unicode status

The Marulipi script is not yet in Unicode. It is not yet in the Roadmap for the Unicode Standard. The [Script Encoding Initiative](https://sei.berkeley.edu/) includes this script in their list of “Scripts Not Yet Encoded”. Contributions here may support their efforts.
